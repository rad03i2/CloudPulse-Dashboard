# Contributing

Thanks for improving CloudPulse Dashboard. Use Node.js 20+, keep changes focused, and do not commit credentials or generated build output.

1. Create a focused branch.
2. Run `npm install`.
3. Add or update tests for behavior changes.
4. Run `npm run check`, `npm test`, and `npm run build`.
5. Open a pull request explaining the behavior and trade-offs.

Keep the HTTP API backward-compatible where practical and document user-visible changes. By contributing, you agree that your contribution is licensed under the repository's MIT License.
